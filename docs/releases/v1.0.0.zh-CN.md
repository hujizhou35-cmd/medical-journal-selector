# 医学选刊工具 V1.0.0 稳定版

[English release](https://github.com/hujizhou35-cmd/medical-journal-selector/releases/tag/v1.0.0) | **简体中文**

**首次使用的默认版本。** 读取医学稿件，核验当前期刊政策，比较分区、时间、适配三条路线；附来源、理由和未核到事项。稳定版是发布状态，不代表推荐没有错误。

## 选择一个下载文件

| 文件 | 用途 |
|---|---|
| `.skill` | 单个Skill安装包；ZIP格式，解压到助手的Skill目录 |
| Codex Plugin ZIP | 含插件元数据与完整Skill；原生导入兼容性未验证 |
| `SKILL.md` | 给其他助手读取的完整单文件指令；不含可选执行脚本 |
