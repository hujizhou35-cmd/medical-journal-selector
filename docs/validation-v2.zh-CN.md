## 较早的本地检查

检查覆盖报告语言、实时来源记录、硬条件、三条路线、政策排除、脱敏、来源使用范围、重复研究、答案隔离、输出封存、失败重试留存、原始准备材料封存、四组匿名比较、真实 100 篇前置门槛、全部 50 篇先封存后揭盲和打包。完整测试共 233 项通过。文档链接和自包含 Markdown 一致性另行通过；合成门槛样例不计入论文数量。

当前语料检查覆盖 150 篇分配材料：输入哈希与准备后的正文一致，有许可和答案身份记录，未发现跨集合的近重复研究，期刊数量上限符合规则。这些程序检查不能排除模型记忆、未识别的重复版本或需要科学判断的问题。
