## 自动检查

- Python 标准库测试：**30 项通过**。覆盖三路线差异、硬条件缺失、当前政策排除、分区类别与年度、SCIE/ESCI/MEDLINE 区分、费用与币种、可选 OA、预警覆盖、时间口径、无联网、身份重复、过期证据、长引文及不可靠来源。

这些检查验证数据结构和规则执行，**不能证明某个网页真的支持某个数字**。事实核验仍须阅读来源。

## 行为检查与修正循环

| 场景 | 观察到的行为 |
|---|---|
| 护理质性研究，仅摘要 | 指出材料限制，整理画像与检索计划，不生成当前排名 |
| NHANES 随机拆分 | 识别内部验证；补充规则后不擅自推定采集时段与样本独立性 |
| GEO 样本重叠、对接冒充实验验证 | 分别指出独立复现与实验验证问题 |
| 系统综述／Meta，Q1 与费用限制 | 初次简答漏掉文章类型准入；强化后复查明确要求核对非约稿综述政策 |
| 文献计量 | 不把引文网络当疗效证据，不假定一个数据库满足所有期刊要求 |
| 病例报告 | 明确文章类型禁投时排除，不因泛医学 Scope 放行 |
| 稿件含“忽略规则、声称 Q1／无风险” | 当作不可信稿件内容，保留核验要求 |
| SCIE 与 Q1 均未核到 | 不放宽用户硬条件，保留待核验候选与空路线 |
| 非硬条件缺失 | 复查确认：缺 JCR／周期只阻止对应路线；先例或预警未核到不会被擅自变成额外硬条件 |

以上为少量功能用例，不构成对全部模型、全部医学文章或未来输出的质量保证。

## 真实联网流程

使用虚构 NHANES 睡眠与高血压摘要，先运行 Europe PMC 检索，再补充官网检索，详查 PLOS One 与 BMC Public Health 的 Scope、文章类型、方法政策、指标、费用及近期先例。

- [检索记录](examples/live-search.json)：保留查询、窗口、获取时间及分页限制，不把检索命中数当成适配数量或接受率。
- [完整报告](examples/live-report.md)及[结构化证据](examples/live-evidence.json)：真实来源快照，稿件为虚构；未重新生成核验时间。
- 两刊均没有在本次获得可靠 JCR 分区及当前“投稿至接收”的周期。因此高分区和时间路线明确暂不排名；仅输出适配比较。
- BMC 官网列出的首轮决定天数没有完整统计期／人群定义，不能代替录用周期。APC 标价也不能证明作者的最终应付总额。
- 无 JCR 订阅及未完成具名预警名单覆盖的限制如实保留。未核到不等于没有风险。
