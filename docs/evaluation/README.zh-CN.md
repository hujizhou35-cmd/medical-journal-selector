# V2 评测

[English](README.md) · [Trainer 教程](../trainer-guide.zh-CN.md) · [中文主页](../README.zh-CN.md)

**状态：正在进行真实流程试运行。尚未宣称 V2 最终准确率结果或正式发布。**

流程试运行发现了缺少 ISSN 时的错误计分，以及全文 XML 提取问题，因此重新开始正式计数。**四篇已揭晓的协议试运行完整保留，不计入正式 100 篇。**现在会递归清除引用格式、声明和审稿历史，并保留 XML 引用标记之后的研究文字；新一轮生成前已更新并封存全部输入哈希。[正式逐例记录和当前发布检查](results.json)给出实际完成数。6 篇尚未评测的许可不符文章、4 篇尚未评测但答案身份未能核实的文章按准入规则排除，用同类别备用文章补足 100／50 配额。一次 900 秒生成超时如实保留；同样输入按 1,800 秒上限重试后完成，模型和配置不变。

修正后的临床试运行说明了几项指标的差别：真实期刊已被检索、传入和评估，但当前准入条件未核清，因此没有进入合格适配名单。摘要基线将它排在第二。这是流程检查，不是正式准确率结果，也不会产生“必须推荐该刊”的规则。原计分和修正记录都在私有运行材料中保留。

第一阶段要求 100 篇不同的开发案例、50 篇未参与调规则的最终测试，比较固定关键词／摘要基线、原 V1 和冻结的 V2 候选。先封存推荐与独立 AI 评审，再揭晓答案。不达标时最多追加一轮：100 篇开发、50 篇全新测试。

真实发表期刊命中和当前推荐合理性分别报告；缺失的 JCR／SCIE 信息不冒充已核验。评审是 AI 会话，不是医学专家。分层的开放全文样本不代表全部医学投稿。

成对比较共用稿件画像、候选检索结果和本次来源快照，测试的是基于这些材料的推荐判断，不等于比较两个版本自主完成全部检索的能力。补充材料链接已记录；尚未阅读的补充内容仍作为方法证据缺口说明。

完成后报告实际案例数、失败、分类结果、Hit@3/5/10 及不确定区间、可用候选覆盖、证据错误、成对评审、规则变化及实际用量／耗时。原文、答案清单和完整日志不进入公开发布包。

这个断点是开发记录，不是准确率估计。用量汇总只包含实际获得的记录，未完成调用的未知用量不算零；调用耗时之和包含并行评审，不等于实验总用时。所有最终推荐和评审封存之前，最终文章标识和答案保持私密。
