# V2 评测

[English](README.md) · [Trainer 教程](../trainer-guide.zh-CN.md) · [候选版实际检查](../validation-v2.zh-CN.md) · [中文主页](../README.zh-CN.md)

目前已完成五篇正式开发案例。前两篇都未能提供有证据支持的可用推荐；第三篇保留了六条来源分类错误，并在独立回归后采用了来源类型澄清。第四篇的盲评将一个病例报告候选计为可用，但揭晓后的诊断指出具体栏目是否接受该文章类型尚未核清。第五篇的第三位评审确认，期刊明确要求投稿工作未发表，因此唯一候选不适用于这份已发表终稿评测材料。上述发现均已保留；两篇案例都没有新增期刊特例规则，因为现有准入门槛已经覆盖这些情况。原始计分、空适配名单、硬错误和未核到字段均完整保留。后续限定范围的来源获取检查修复了官网域名、文章类型政策链接和刊名／ISSN 查询；最多六本期刊共用原定的十八个初始来源、十二个后续链接上限。Crossref 期刊记录只支持身份核对，不能证明投稿许可、收录或指标。这些获取检查不代表推荐得分提高，需要用后续新案例验证。

在生成前，另有八篇尚未评测的输入需要补充遮蔽研究注册编号。修正保留注册事实、100／50 分配和前两篇已完成输入，并同步用于检索限制。历史协议记录保持不变。

第三篇正式案例出现六条来源分类错误：已有依据的期刊身份记录被输出为普通文献来源。单独校验重放、新的生成和两个独立会话评审通过后，采用了按记录区分来源类型的通用澄清。原始六条错误和空适配名单仍保留在计分结果中；揭晓后的回归不增加案例数，也不能证明性能提高。

**状态：正在进行真实流程试运行。尚未宣称 V2 最终准确率结果或正式发布。**

流程试运行发现了几项准备程序的问题：缺少 ISSN 时的错误计分、正文混入出版信息、科学链接文字误删、文末的伦理／知情同意／数据可用性声明被漏掉，以及 XML 中暴露编辑或审稿人信息。**十一篇协议试运行（包括中断的案例）完整保留，不计入正式 100 篇。**现在隐藏出版线索，同时保留科学链接文字、引用之后的正文、普通医学术语和必要的研究声明。公共数据集编号保留，本研究试验注册号使用一致代号，禁止用研究专属编号寻找论文答案。材料检查后重新固定输入哈希和 100／50 配额。[保留的协议试运行](protocol-trials.json)与[正式逐例记录和当前发布检查](results.json)分开计数。6 篇尚未评测的许可不符文章、4 篇答案身份未能核实的文章按准入规则排除，用同类别备用文章补足配额。实际超时和连接中断均如实保留；重试仍使用 1,800 秒上限和相同模型配置。

修正后的临床试运行说明了几项指标的差别：真实期刊已被检索、传入和评估，但当前准入条件未核清，因此没有进入合格适配名单。摘要基线将它排在第二。这是流程检查，不是正式准确率结果，也不会产生“必须推荐该刊”的规则。原计分和修正记录都在私有运行材料中保留。

第一阶段要求 100 篇不同的开发案例、50 篇未参与调规则的最终测试，比较固定关键词／摘要基线、原 V1 和冻结的 V2 候选。先封存推荐与独立 AI 评审，再揭晓答案。不达标时最多追加一轮：100 篇开发、50 篇全新测试。

真实发表期刊命中和当前推荐合理性分别报告；缺失的 JCR／SCIE 信息不冒充已核验。评审是 AI 会话，不是医学专家。分层的开放全文样本不代表全部医学投稿。

成对比较共用稿件画像、候选检索结果和本次来源快照，测试的是基于这些材料的推荐判断，不等于比较两个版本自主完成全部检索的能力。补充材料链接已记录；尚未阅读的补充内容仍作为方法证据缺口说明。

完成后报告实际案例数、失败、分类结果、Hit@3/5/10 及不确定区间、可用候选覆盖、证据错误、成对评审、规则变化及实际用量／耗时。原文、答案清单和完整日志不进入公开发布包。

这个断点是开发记录，不是准确率估计。用量汇总只包含实际获得的记录，未完成调用的未知用量不算零；调用耗时之和包含并行评审，不等于实验总用时。所有最终推荐和评审封存之前，最终文章标识和答案保持私密。

`call_outcomes` 单独统计真实调用状态。重试成功可以完成一篇案例，但此前的连接或平台失败仍然计数。没有获得用量记录不等于没有消耗。

一个真实开发案例中，两份独立评审发现了同一个没有依据的研究类型排除判断。新增的稿件方法核对要求已用真实重跑和两份新评审检查，原始错误及负面结果仍然保留；这次回归不能证明改规则必然提高性能。`hard_failures` 统计保留的错误标记，同一问题可能被多次指出；`hard_failure_cases` 统计涉及的案例数。用量包含真实回归和未完成案例已有的调用记录，但这些调用不增加完成案例数。

字段覆盖统计取自原始封存结果，分别列出模型标注的已核验、未核到和状态格式缺失。模型写了“已核验”不等于独立检查已经确认正确；修正后的结果也不会覆盖原始统计。
