# Host compatibility and verification scope

**English** | [简体中文](validation-v2.zh-CN.md) · [Installation](getting-started.md)

Rules and scripts in Skill/Plugin packages can be checked, but successful packaging does not prove actual loading in every host. Native plugin import and end-to-end behavior across all hosts are not verified. Single-file mode depends on the assistant reading instructions and following the inlined references.

Windows/Linux and Python 3.10/3.12 checks validate software behavior, structure and builds. Separate targets handle stable Selector, experimental Selector and Trainer. V1/V2 generated bytes must match their original published hashes.

[Historical host checks](validation.md) and [original V2 download verification](releases/v2.0.0-experimental.1-verification.json) retain their recorded scope; the original seven-asset inventory is not the current curated list. Use the [release page](releases/v2.0.0-experimental.1.md) for current files and hashes. Software checks do not establish improved recommendation accuracy; [experimental results](evaluation/100-plus-50.md) are reported separately.
