# 用 Trainer 改进选刊 Skill

[English](trainer-guide.md) · [项目主页](README.zh-CN.md)

**Medical Journal Selector Skill Trainer** 用于组织迭代实验。只想为一篇稿件选刊时，请使用选刊 Skill。

## 三步使用

1. 提供选刊 Skill 快照和有权使用的文章，提前确定开发／测试分组与模型设置。
2. 用新会话读取脱敏稿件并选刊，先固定推荐和独立来源评审，再揭晓真实发表期刊。
3. 将有证据的问题变成通用规则，复查其他类型，再用未参与改规则的文章验收。

```text
使用 medical-journal-selector-skill-trainer 评测这个选刊 Skill。
稿件先脱敏；推荐与独立评审封存后才能揭晓真实期刊。
保留完全未参与改规则的最终测试集。
说明哪些规则值得修改，以及发布条件有没有通过。请用中文回复。
```

## 怎样算一次迭代

一篇不同文章完成选刊、盲评、揭晓、问题分析，并给出有依据的修改或“无需修改”决定。重试和回归测试不增加次数。未命中原刊不一定选错；已发表论文也不能提供拒稿分母或录用概率。

## 本项目的 V2 评测

第一阶段为十类文章共 100 篇开发、50 篇封存测试；开发已完成 21／100 篇，最终测试仍为 0／50 篇。不达标时只追加一轮：100 篇开发、50 篇全新测试。发布门槛未通过就不发布正式 V2。[方法和实际结果](evaluation/README.zh-CN.md)

## 安装

Trainer 文件夹名为 `medical-journal-selector-skill-trainer`。Codex 放进 `.agents/skills/`，Claude Code 放进 `.claude/skills/`。通过验收后，Release 会同时提供独立便携指令文件。不要改成选刊 Skill 的名字，也不要覆盖它的文件夹。

[Trainer 源码](../skills/medical-journal-selector-skill-trainer/)包含在本项目中。公开下载链接在实际发布后补齐。

## 自动运行与边界

Python 辅助脚本负责取得许可明确的论文、脱敏、启动新的受限 Codex 会话、封存和汇总。模型权限由已有宿主提供。其他 Agent 可以按便携规则处理，但可审查的盲测需要真实的会话和检索隔离。

本项目采用 AI 评审，不等于医学专家评审。模型可能记住公开文章，最终发表版也可能经过审稿修改。原文、答案清单和完整模型日志不进入发布包。

十个文章主类各有队列，每轮每类最多一篇，默认最多十个工作者和十个同时模型调用。单篇内部仍按准备、选刊、盲评、揭晓和决定的顺序进行。最新十类并行仍保留失败状态，八篇完成闭环、两条流程未完成。小连接检查已通过，[五个工作者、五路同时模型调用的恢复波](evaluation/current-wave.json)已实际启动，十类逻辑队列全部保留；运行中不增加完成数。启用调度器前先阅读[并行执行计划](evaluation/parallel-execution-plan.zh-CN.md)。

最终测试要求开发记录已完整。第一次推荐前封存两项排序基线和共用输入；两名最终评审都检查四份匿名比较结果。整批五十篇核验通过后，揭盲和评分角色才读取答案。程序已实现这些门槛并完成合成检查，真实最终评测尚未开始。
